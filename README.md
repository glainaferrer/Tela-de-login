Uma interface de login elegante e minimalista desenvolvida com **HTML5** e **CSS3**. O projeto foca em um design moderno com tema escuro, utilizando gradientes e efeitos visuais suaves para proporcionar uma melhor experiência ao usuário.

## ✨ Funcionalidades

- **Design Responsivo:** Layout adaptável para diferentes tamanhos de tela.
- **Estilização Avançada:**
  - Fundo com gradiente linear (Dark Blue).
  - Efeito de linha decorativa no topo do formulário (`linear-gradient`).
  - Texto do título com efeito de gradiente e `background-clip: text`.
- **Inputs Estilizados:** Campos de e-mail e senha com design limpo e foco visual.
- **Botão de Ação:** Botão de "Entrar" com destaque visual.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do formulário.
- **CSS3:** Estilização, Flexbox para layout, variáveis de cores e efeitos de transparência (opacidade).
- **Google Fonts:** Tipografia moderna (implícito no design).
